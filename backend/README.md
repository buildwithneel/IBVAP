# IBVAP Backend + AI Computer Vision Service
**SIH 26187 — AI-Based Intelligent Video Analytics Platform for Border Surveillance**

Production-ready real backend & computer vision inference pipeline built with FastAPI, PyTorch, Ultralytics YOLOv8, OpenCV, ByteTrack, SQLAlchemy, PostgreSQL/SQLite, and WebSockets.

---

## 🔒 Absolute Data Integrity Guarantee

This implementation adheres strictly to the **Absolute Data Integrity Rule**:
* **Zero fake data**: NO simulated camera records, fake RTSP streams, fake detections, dummy alerts, or random event scores.
* **Real Inputs Only**: Real video files uploaded via `POST /api/v1/streams/upload`, real Webcams, or real RTSP streams provided by operator.
* **Empty State**: When clean, all endpoints return `{"cameras": [], "total": 0}` and `{"events": [], "total": 0}`.

---

## ⚡ Core Architecture & Pipeline

```text
REAL VIDEO SOURCE -> INGESTION -> FRAME PROCESSOR -> AI INFERENCE (YOLOv8 + ByteTrack)
 -> ANPR & FACE -> ZONE & RULE ENGINE -> DEDUPLICATION & RISK SCORE FUSION
 -> EVIDENCE GENERATION -> SHA-256 AUDIT CHAIN -> REST API & WEBSOCKET BROADCAST
```

### Key AI & Business Capabilities
1. **Person & Vehicle Detection**: Ultralytics YOLOv8 (CPU/CUDA support).
2. **Multi-Object Tracking**: Persistent ByteTrack track IDs across frames.
3. **Polygon Virtual Fence**: Ray-casting point-in-polygon entry detection (`outside -> inside`).
4. **Loitering Engine**: Real track-duration tracking against `LOITERING_THRESHOLD_SECONDS`.
5. **Night Window Detection**: Configurable night window (`NIGHT_START_TIME` to `NIGHT_END_TIME`) + frame luminance calculation.
6. **ANPR Engine**: Vehicle localization -> crop -> preprocessing -> OCR -> text normalization. Zero hallucinated characters.
7. **Face Detection**: Face bounding box detection without identity guessing.
8. **Explainable Risk Scoring**: Deterministic score calculation (0–100) with explicit factor reasons.
9. **Tamper-Evident SHA-256 Audit Ledger**: Cryptographic hash chain with `/api/v1/audit/verify` verification endpoint.

## 🚀 Quick Start Guide

### 1. Direct Python Execution
```bash
cd backend
python -m venv venv
# On Windows:
venv\Scripts\activate
# On Linux/Mac:
source venv/bin/activate

pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
Swagger API docs will be available at `http://127.0.0.1:8000/docs`.

### 2. Docker Compose
```bash
cd backend
docker-compose up --build -d
```

## 📡 Key API Endpoints

* `POST /api/v1/streams/upload`: Upload real video file to run AI pipeline.
* `GET /api/v1/cameras`: List cameras (Empty `[]` if none configured).
* `GET /api/v1/events`: List real surveillance events generated by AI pipeline.
* `GET /api/v1/alerts`: List alerts.
* `GET /api/v1/audit/verify`: Verify SHA-256 audit log integrity chain.
* `WS /ws`: WebSocket feed for live event notifications.
